# Reelhouse v8 — React/Vercel

This is the v8 Reelhouse UI packaged as a Vite + React application.

The original HTML/CSS/JS pages are preserved byte-for-byte under `public/legacy/` and rendered through a minimal React shell. This deliberately avoids changing the existing design, interactions, or styling while giving Vercel a standard React/Vite project structure.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
